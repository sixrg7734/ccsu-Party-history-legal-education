# 党史普法竞赛 - 自动答题脚本

用于长沙学院党史普法竞赛学习页面的自动答题脚本，自动循环：显示答案 → 选择正确选项 → 提交 → 下一题。

## 使用方法

1. 打开学习页面 `http://ggwjs.ccsu.cn:8060/pfweb/learn.html`，登录后进入做题界面
2. 按 `F12` 打开开发者工具，切到 **Console（控制台）** 标签
3. 如果 Chrome 提示需要允许粘贴，输入 `允许粘贴` 后回车
4. 复制 `auto_answer.js` 里的全部代码，粘贴到控制台，按回车运行

## 运行流程

```
点击"确定" → 显示正确答案 → 自动选中正确选项 → 再次点击"确定" → 自动跳"下一题" → 循环
```

- 每道题约 4 秒
- 支持单选题和多选题
- 全部题目完成后自动停止

- ## 原理
- 这个做的比较无脑，点一下就出答案了

## 注意事项

- 运行期间不要手动点击页面，避免干扰脚本
- 控制台会实时打印当前题号和答案信息
- 如弹出提示框（如"没有下一题"），手动关闭即可
- 脚本不会修改服务器数据，仅自动完成答题操作
